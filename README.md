🔖 Bookmark Manager App

A modern and responsive Bookmark Manager built with HTML, Sass, and Vanilla JavaScript to organize bookmarks with a clean and intuitive user experience.

✨ Features
➕ Add, edit, archive, and delete bookmarks
🔍 Real-time search
🏷️ Tag-based filtering
📌 Pin important bookmarks
📋 One-click URL copy
🌐 Direct website access
📊 Multiple sorting options
💾 Local Storage persistence
📱 Responsive design
 # Light and Dark Mood
   
💡 Highlights

Built entirely with Vanilla JavaScript, featuring reusable components, dynamic filtering and sorting, state management, and optimized DOM updates. The project emphasizes maintainable code, thoughtful UI interactions, and scalable architecture while solving real-world user experience challenges.
